# usflow — 美股 APP 設計規劃（草案 v0.1）

> 暫定名稱：**隔洋觀火**（取「隔岸觀火」：人在台灣、看懂一夜美股，再決定今天台股怎麼走）
> 狀態：規劃階段，尚未開發。本文件的資料來源**尚未實測**（開發環境無對外網路），
> 進入 Phase 0 時須逐一驗證。

---

## 1. 為什麼要做、做給誰

### 目標使用者
1. **用複委託／海外券商買美股的台灣散戶** —— 語言、時差、稅務是三大門檻。
2. **只做台股、但每天早上要看美股臉色的人** —— 他們真正想知道的是「昨晚美股對我今天的台股有什麼影響」。

### 痛點
| 痛點 | 現況 | 我們的解法 |
|---|---|---|
| 時差：美股收盤是台灣清晨 04:00/05:00 | 早上醒來要翻好幾個英文網站 | 06:30 自動產出中文晨報 |
| 英文財報看不懂 | 只能看新聞二手消息 | SEC 官方財報數字直接中文化、圖表化 |
| 不知道美股跟台股的關聯 | 靠記憶「輝達漲→廣達漲」 | 用 twflow 既有的 28 條產業鏈，把美股龍頭接到台灣供應鏈 |
| 股利被扣 30% 預扣稅、複委託手續費 | 自己算 | 內建台灣人視角的「實拿」試算 |

### 差異化（跟 Yahoo、TradingView、Finviz 比）
- **美股→台股連動**是我們獨有的：twflow 已經有台股板塊、產業鏈拓撲與每日法人資料，別家美股 APP 沒有。
- 完全中文、免帳號、免費、PWA，延續 SunDown Studio 既有產品風格。

## 2. 核心觀念：美股沒有「三大法人日報」

twflow 的核心訊號是證交所每天公布的三大法人買賣超。**美股沒有對應的免費日資料**，
所以不能把 twflow 原封不動搬過去。可替代的訊號：

| 想知道的事 | 台股（twflow）| 美股可用的替代 | 頻率 |
|---|---|---|---|
| 大資金在買什麼 | 三大法人買賣超 | 板塊 ETF 的成交值 × 漲跌（資金流 proxy）| 日 |
| 空方力道 | 融券 | FINRA 每日 short volume | 日 |
| 公司內部人動向 | 董監持股 | SEC Form 4 內部人買賣 | 事件 |
| 機構持股變化 | 投信持股 | SEC 13F（季報，延遲 45 天）| 季 |
| 基本面 | 月營收／季報 | SEC XBRL companyfacts | 季 |

> ⚠️ 「ETF 成交值 × 漲跌」只是代理指標，不是真實資金流入流出，UI 上必須明確標示，
> 不能寫成「外資買超」那種語氣。

## 3. 功能規劃

### MVP（Phase 1）
| 頁面 | 內容 |
|---|---|
| **晨報**（首頁）| 四大指數、費半、VIX、10 年債、美元指數；11 大板塊漲跌熱力圖；漲跌幅前 10；一句話摘要 |
| **台美連動** | 台積電 ADR 溢價（TSM vs 2330 換算匯率）；美股龍頭 → 台灣供應鏈對照（例：NVDA → 鴻海、廣達、緯創…），並帶出這些台股在 twflow 的最新法人動向 |
| **個股頁** | 價格走勢＋MA；EPS／營收／毛利率（SEC 季報）；殖利率與「台灣人實拿」試算；下次財報日 |
| **自選股** | localStorage，與 twflow 同機制 |
| **搜尋** | 中英文名稱、代號（中文名稱表需自建，先涵蓋 S&P 500＋常見 ADR/ETF）|

### Phase 2
- 板塊泡泡圖（沿用 twflow 的四象限＋symlog 視覺）
- FINRA 做空比例異常、Form 4 內部人大額買進事件流
- 財報週行事曆（台灣時間）

### Phase 3
- 13F 大型機構季度持股變化
- 「美股晨報 → 今日台股觀察名單」自動產生（台美連動的延伸）
- Web Push（與 twflow ⑪ 共用後端）

### 明確不做
- 即時報價、下單、帳戶串接、個股推薦或買賣建議（法遵考量，見 §8）

## 4. 資料來源（全部需在 Phase 0 實測）

| 用途 | 候選來源 | 備註 |
|---|---|---|
| 公司清單／CIK 對照 | `www.sec.gov/files/company_tickers.json` | 官方、免費；需帶 User-Agent（含聯絡 email）|
| 基本面 | `data.sec.gov/api/xbrl/companyfacts/CIK##########.json` | 官方、免費；限速 10 req/s |
| 內部人 | SEC EDGAR Form 4 | 官方 |
| 做空量 | `cdn.finra.org/equity/regsho/daily/CNMSshvolYYYYMMDD.txt` | 官方、免費 |
| 日線價量 | Stooq CSV／其他免費日線來源 | **最大風險**：非官方、可能隨時改版或限流，需備援 |
| 匯率 | 台灣央行／臺銀牌告 | ADR 溢價換算用 |
| 台股端 | 本 repo `twflow/web/data/*.json` | 直接引用，不重抓 |

**價量來源是整個專案最脆弱的一環。** 建議 `fetch` 層抽象成 provider 介面，至少準備兩個來源，
並沿用 twflow 的 `sanity_check.py` 作法：數字不合理就不提交。

## 5. 系統架構（沿用 twflow，零伺服器）

```
GitHub Actions（台灣時間 06:30，週二～週六）
  ├─ fetch_prices.py      只抓缺的交易日，逐日檔 append-only
  ├─ fetch_sec.py         每週一次；只更新有新 filing 的公司
  ├─ fetch_finra.py       每日做空量
  ├─ build_web.py         產出 web/data/*.json
  ├─ build_links.py       讀 twflow 產業鏈，產生美→台對照
  └─ sanity_check.py      失敗就中止，不提交
        ↓ commit
GitHub Pages：usflow/web/（純前端 PWA，資料就是靜態 JSON）
```

- 目錄結構比照 `twflow/`：`scripts/`、`data/`、`web/`、`requirements.txt`、`README.md`
- 新增 workflow `.github/workflows/usflow-daily.yml`，concurrency group 與 twflow 分開
- 美國夏令／冬令時間會讓收盤時間差 1 小時；排程固定在 06:30 兩者都安全
- 美股假日：以 NYSE 假日表＋「當日無資料就跳過」雙重處理

### 資料量估算
- S&P 500＋那斯達克 100＋常見 ETF/ADR ≈ 650 檔 × 60 日 × ~50 bytes ≈ 2 MB，與 twflow 同量級
- SEC companyfacts 原始檔很大，**只萃取需要的欄位**再落檔，不把原檔進 git

## 6. 台美連動的資料模型（核心差異化）

```json
{
  "us": "NVDA",
  "name_zh": "輝達",
  "chain": "AI 伺服器",
  "tw_links": [
    {"code": "2317", "role": "組裝", "source": "manual"},
    {"code": "2382", "role": "組裝", "source": "manual"},
    {"code": "3231", "role": "組裝", "source": "manual"}
  ]
}
```

- 第一版**人工建表**（先做 30 檔美股龍頭），`source` 欄位記錄依據
- 之後可用報酬相關性（`twflow/scripts/common.py` 已有相關係數工具）驗證或補強：
  美股 T 日報酬 vs 台股 T+1 日報酬的領先相關
- 頁面呈現「關聯」而非「因果」，避免暗示操作建議

## 8. 法遵與風險

- 沿用 twflow 免責聲明：僅彙整公開資料，非投顧，不構成投資建議
- 不做個股評等、目標價、買賣訊號；「台美連動」只呈現歷史關聯
- SEC 要求 User-Agent 帶真實聯絡資訊並遵守限速
- 非官方價量來源的使用條款需在 Phase 0 確認是否允許自動抓取與再散布

| 風險 | 影響 | 對策 |
|---|---|---|
| 免費價量來源失效 | 整站停擺 | provider 抽象＋雙來源＋sanity check |
| ETF 資金流 proxy 被誤讀 | 誤導使用者 | 名稱改叫「板塊熱度」，附說明 |
| 中文名稱表維護成本 | 搜尋體驗差 | 先只涵蓋 ~650 檔，其餘顯示英文 |
| 台美對照表主觀 | 公信力 | 標註依據，Phase 2 用相關性驗證 |
