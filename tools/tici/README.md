# 提詞挈領

> 化用「提綱挈領」。`prompt` 的中文本義就是**提詞**——劇場裡的提詞員叫 prompter。
> 挈領，抓住要領。合起來：把提示詞的要領抓起來。

玩著學提示詞工程。走進夜色裡的碑林群島，用「選字刻碑」的方式把提示詞一段一段組出來，
由一套完全離線的評分引擎逐條檢核，給出 S / A / B / C 四個等第。

不需要帳號、不需要後端、不發任何外部請求。開一個靜態伺服器指到這個資料夾就能玩。

```bash
python -m http.server 3005 --directory tools/tici
```

## 十一種題板

即時否決型（選錯會被擋下並附上白話說明，可以一直試到對，但第一次的判斷會反映在評等上）：

- **碑文刻寫 carve** — 逐段從候選句子中挑出對的，把提示詞組起來
- **守門叩問 gate** — 單選，兩三個看起來都對的作法裡挑真正站得住的那個
- **模板填格 slot** — 把官方模板的空格填成可驗收的內容
- **瑕碑修補 repair** — 先指出壞掉的那一行，再選出修法
- **位序排列 order** — 依序點選，排出正確的資訊位置

交卷後揭曉型：

- **沙盤篩選 sift** — 複選
- **冗贅刪修 trim** — 刪掉沒有作用的句子
- **工坊調度 dispatch** — 把每個情境分派到對的模型／工具／權限層
- **對照配對 pair** — 狀況對處置
- **約束儀盤 gauge** — 轉出正確的參數組合
- **自由書寫 write** — 打字作答，交卷後可看參考寫法

## 評分怎麼運作

所有題板最後都會化約成同一樣東西：**一段組裝後的提示詞文本**，加上**一個選擇正確度**。
兩者餵進同一套引擎，所以不同題型的評等是同一把尺。

檢核是結構辨識，不是關鍵字比對——關鍵字必須出現在對的位置、帶著具體內容才算數。
例如「限制可量測」要看到數字，「允許回答不知道」要看到「找不到 → 就回答什麼」的完整句式，
「首尾各放一次指令」要看到同一條指令出現兩次且中間隔得夠遠。

另有兩條乘性防呆：空白或極短的回應無法評分；把技法名詞排一排也不算會用。
選擇正確度同時是一個乘數，全選錯的答案不會因為題目骨架本身帶著段落標籤就拿到及格分。
