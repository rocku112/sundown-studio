# 交易健檢

線上版：https://rocku112.github.io/sundown-studio/tools/tradecheck/

把已實現的交易紀錄貼進來，回答四個問題：獲利是實力還是運氣、有沒有贏過同期放著不動的 0050、是不是靠賭重大消息、是不是靠一兩筆撐起來。另有「老師宣稱檢驗」、「回檔買進回測」和「詐騙檢查」（165 官方涉詐網站查詢、話術掃描）。

交易紀錄只在使用者的瀏覽器內計算，頁面不會上傳任何交易資料；只會下載下面的公開資料檔。

## 檔案

| `index.html` | 整個工具（單檔，無外部程式庫） | 手寫 |
| `gen_data.py` | 產生下面兩項資料 | 每個交易日由 `twflow-daily.yml` 執行 |

| `gen_dip.py`、`dip/index.json`、`dip/00.json`～`31.json` | 回檔買進回測：每檔股票與 ETF 從 60 日高點回檔 10／15／20／25% 時買進，持有 20／60／120 個交易日的報酬統計與每次觸發明細，以及「每天都買」的對照組 | `swing/data/prices` 官方日線（含息還原），每週五重算 |

## 方法

- **運氣機率**：每筆損益扣掉平均值（假設沒有優勢），以區塊自助抽樣（區塊長度 n 的立方根，保留連續交易的相關性）重抽 2,000～10,000 次，計算平均 ≥ 實際平均的比例。
- **穩定度**：前後半段各自的平均與 t 值；兩半都賺才算穩定。
- **所需筆數**：單尾 5%、檢定力 80%，依目前平均與標準差推算。
- **0050 對照**：每筆以買進日、賣出日（取當日或之前最後一個交易日）的 0050 含息還原收盤計算同期報酬，乘上投入金額；不計 0050 的手續費與稅。
- **事件暴露**：買進日 < 事件反應日 ≤ 賣出日，視為抱著過了該事件。美國事件與台灣盤後公布的事件，反應日為台股下一個交易日。
- **回檔買進**：60 日高點含當天；第一次跌破門檻當天收盤買進；觸發後要等再創 60 日新高才算下一波；持有天數以該股自己的交易日計，未滿的列為進行中。只收錄目前仍在交易的股票，所以個股結果有倖存者偏差。
- **老師宣稱**：以宣稱的賺賠比推出「零期望值」下的單筆勝率，用二項分布算出做到宣稱勝率以上的機率，再乘上市場上的老師數量估計倖存者。

所有數字都是對過去紀錄的統計，不是預測，也不是投資建議。
