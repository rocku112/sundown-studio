# 早謀遠算

台灣退休規劃試算。整合勞保老年給付、勞退新制、勞基法舊制、企業福利信託、現有資產與定期投資，依生命表餘命換算退休月領，並對照最低生活費算出缺口。

純靜態網頁、無建置步驟、無後端；資料只存在瀏覽器 localStorage（`zaomou_v2`）。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 介紹頁與快速試算 |

| `js/data.js` | **年度參數**：勞保分級表、勞退提繳上限、生命表、最低生活費。每年更新只改這裡 |
| `js/engine.js` | 計算引擎（純函式，不碰 DOM） |
| `js/state.js` | 預設值、儲存、匯出入、舊版設定遷移 |
| `js/app.js` | 試算介面 |
| `js/charts.js` | SVG 圖表 |
| `test/engine.test.mjs` | 引擎測試 |

## 每年要更新的參數

- 勞保投保薪資分級表（最低工資調整時，第 1 級會跟著變）
- 衛福部與六都公告的下一年度最低生活費（通常 9–10 月公告）
- 生命表平均餘命（內政部每年 8 月公布簡易生命表）

## 計算假設

- 勞保：A 式 `投保薪資 × 年資 × 0.775% + 3,000`、B 式 `投保薪資 × 年資 × 1.55%` 擇優；依出生年次決定法定請領年齡，提前／延後每年 ∓4%，各以 5 年為限；年資未滿 15 年改算一次金。投保薪資維持目前級距。
- 勞退：雇主 6% ＋自提，提繳工資上限 150,000，依薪資年增率逐月累積、月複利滾存。未填專戶餘額時，依 94 年 7 月新制施行後的年資回推估算。
- 舊制：前 15 年每年 2 基數、之後每年 1 基數，上限 45 基數，以推估的退休時月薪近似平均工資。
- 一筆錢換月領：「生命表除數」直接除以提領月數；「年金化」以退休後報酬邊領邊滾、到預期壽命剛好領完。
- 金額皆為退休當年名目值，另以通膨率折算今日幣值。

## 舊版

舊版是單檔 React 編譯輸出（`nuclear-bachelor-calculator.html`），沒有原始碼。新版重寫時一併修正：配偶的薪資成長率與報酬率被重複除以 100、配偶沿用本人年齡、匯出設定讀錯 localStorage key、現金資產無法輸入金額、圖表年齡軸以退休年齡起算、勞保分級表過期等。舊版存在瀏覽器的設定與匯出的 JSON 會自動轉成新格式。
