關於 HEIC / JFIF

HEIC 是 Apple 裝置預設的照片格式，畫質優但 Windows 不易開啟，轉換後可得到通用 JPG。JFIF 其實就是 JPEG，只是副檔名不同——這裡直接無損改回 .jpg，不重新壓縮、不掉畫質。

使用提示
• 從 iPhone 直接拖入
• 多張可一次全選
• 建議品質 85% 以上

格式

.heic .heif .jfif → .jpg

• 改字：點原文字→自動蓋白底、帶出原文、自動比對原字體（黑/明/楷/等寬＋粗斜體）供修改（彩色/圖片底會有補丁、不自動重排，可再微調）
